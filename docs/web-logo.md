# EGAILE web logo

The website uses a transparent web adaptation of the emblem supplied in `EGAILE Logo on the wall.png`. The supplied wall image remains unchanged at its original Drive location.

- `public/brand/egaile-mark.png`: transparent cyan/cobalt and metallic-silver emblem, adapted with image generation from the supplied reference and sized for the web.
- `src/app/icon.png`: browser icon derived from the same emblem.
- `src/components/BrandLogo.tsx`: shared accessible mark, live-text EGAILE wordmark and supplied “Transformational technology advisory” tagline.

The live-text wordmark is a website treatment, not an exact reproduction of the dimensional lettering in the wall mockup. The compact mobile header and admin sidebar hide the long tagline for readability. Dark and light variants keep the name legible. The decorative symbol has empty alternative text because each enclosing home link is labelled EGAILE home.

Header, footer, admin sign-in and workspace share this component. The official master logo should be retained separately; this generated web adaptation is not a vector master or registration artwork.
